# Breast Cancer Prediction using Random Forest Classifier

A machine learning project built with Python and Scikit-Learn that predicts breast cancer diagnosis using the **Breast Cancer dataset** (`load_breast_cancer`). The project implements an ensemble classification model via a **Random Forest Classifier** (`RandomForestClassifier`)[cite: 4].

## 📋 Features

* **Data Loading & Prep**: Loads the built-in breast cancer dataset, creates a Pandas DataFrame, and splits data into training and test sets (`train_test_split`)[cite: 4].
* **Machine Learning Model**: Trains a supervised `RandomForestClassifier` with ensemble parameters (such as `n_estimators=100` and `max_depth=4`)[cite: 4].
* **Model Evaluation**: Assesses model performance and generalization capability using accuracy scores across training and test splits[cite: 4].

## 🛠️ Tech Stack

* **Python**[cite: 4]
* **Pandas & NumPy** (Data manipulation)[cite: 4]
* **Scikit-Learn** (Dataset, Random Forest Classifier, metrics, and splitting utilities)[cite: 4]
